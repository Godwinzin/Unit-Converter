# Unit Converter

A responsive, interactive web-based unit converter built with HTML, CSS, and Vanilla JavaScript. Features a modern 3D card-flip animation interface with support for length, volume, mass, temperature, and time conversions.

---

## Features

- **3D Card Flip Animation**: Smooth CSS 3D flip effects using custom cubic-bezier transitions.
- **Multiple Conversion Categories**:
  - **Length**: Meters, Feet, Yards, Kilometers, Miles
  - **Volume**: Liters, Gallons, Milliliters
  - **Mass**: Kilograms, Pounds, Grams
  - **Temperature**: Celsius, Fahrenheit, Kelvin
  - **Time**: Seconds, Minutes, Hours, Days
- **Responsive Layout**: Custom CSS Grid layout optimized for mobile, tablet, and desktop views.
- **Pure Vanilla JS**: Zero dependencies or external frameworks required.
